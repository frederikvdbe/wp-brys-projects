# Brys Projects — copy reference

Read this before writing any copy for brys-projects.be.
Based on research of Belgian and Dutch microcement sites (September 2026) and the copy already on the site.

## The business

- Brys Projects: finishing work (microcement, interior finishing, bathrooms) in Sint-Denijs-Westrem, Gent.
- Region: Oost-Vlaanderen and around.
- Main action on every page: request a quote (`/contact#offerte`).
- Few project photos. Copy and material close-ups carry the site, not large galleries.

## Sitemap

| Page | Job of the copy |

## Tone of voice

| Rule | Brys does | Avoid |
|---|---|---|
| Address | Formal **u / uw**. Brys is **wij** | je / jij, mixing u and je |
| Sentences | Short. One fact per sentence. 6–15 words | Long sentences with several commas |
| Headlines | Calm statement, 2–6 words, may use `<br>` | Exclamation marks, questions in every headline |
| Register | Plain, sure, quiet. Like a craftsman who explains | Hype, superlatives ("de beste", "uniek", "perfect") |
| Language | Belgian Dutch: werf, oplevering, offerte, stalen | Netherlands-only terms, like "klus" |
| Proof | Concrete facts: mm, days, own team, fixed price | Vague claims: "jarenlange ervaring", "kwaliteit staat centraal" |

Examples already on the site that set the tone:

- "Een ruimte krijgt haar karakter in de laatste laag."
- "Wij werken met een eigen ploeg, zonder onderaannemers."
- "U kiest, wij voeren uit."
- "Hete potten zet u op een onderlegger." (honest limit, builds trust)

## What the market says (and Brys should not repeat)

Almost every competitor uses the same words. Using them makes Brys look the same.

| Worn word or claim | Seen on | Use instead |
|---|---|---|
| naadloos (in every headline) | all sites | Use once per page at most. Show it: "zonder voeg of drempel" |
| duurzaam, tijdloos, verfijnd | most sites | A fact: layer thickness, how long it lasts, what it resists |
| vakmanschap / ambachtelijk vakwerk | most sites | What the craft looks like: "met de hand aangebracht, laag per laag" |
| "Ontdek de kracht van…" | BCreative | A plain statement of the result |
| "Verfijnd. Naadloos. Tijdloos." (three-word fragments) | Studio ODÓ, Microcement Badkamer | One full, calm sentence |
| "jarenlange ervaring" | many | A number or a fact about the team |
| "Lees meer" / "CONTACTEER ONS!" | several | A specific link label (see CTA table) |

## What the stronger sites do well

The most convincing sites (Microcement Studio, Adec, KCBerry) are the most **specific**:

- Price range per m² and minimum surface
- Duration: "vloer in 1 week", "4–5 werkdagen", drying time
- Layer thickness: 2–3 mm
- Warranty in years
- Number of colours, samples on request
- Named towns in the region

Brys should match this level of detail. Only use facts that Brys confirms. Mark unknown facts as `[TE BEVESTIGEN: …]`, never guess a number.

## CTA labels

| Use | Label |
|---|---|
| Main action | Vraag een offerte aan |
| Projects | Bekijk onze realisaties |
| Material | Ontdek microcement |
| Process | Bekijk onze werkwijze |
| Samples | Vraag stalen aan |
| Contact, soft | Stel uw vraag |

- Verb first, u-form implied, no exclamation mark, sentence case.
- Market standard is "vrijblijvende offerte" or "gratis offerte". Only use "gratis" if Brys confirms it.

## FAQ topics the market answers

Every serious competitor answers these. The Brys FAQ should cover them too:

- Wat kost microcement per m²?
- Hoe lang duren de werken? Hoe lang moet het drogen?
- Kan microcement over bestaande tegels?
- Is het geschikt voor vloerverwarming?
- Is het waterdicht in de douche?
- Hoe onderhoud ik het?
- Welke kleuren zijn er? Kan ik stalen zien?
- Wat is het verschil met beton ciré / gietvloer / Mortex?
- Hoe lang gaat het mee? Is er garantie?
- Wat zijn de nadelen? (Adec answers this openly; honesty here builds trust)

## Where Brys can stand apart

- **Eigen ploeg**, no subcontractors, same people on site every day.
- **Vaste prijs** after a visit on site.
- **Eén aanspreekpunt** from first talk to handover.
- **Stalen bij het eerste bezoek**, seen in the light of the client's own room.
- **Not only microcement**: also interior finishing, so one partner for the whole finish.

Build the main point of each page on one of these.
